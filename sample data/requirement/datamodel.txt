1. DATABASE OVERVIEW
--------------------------------------------------------------------------------
Engine: SQLite 3, single file, offline-capable
Access: only via services/ layer (agents never raw-SQL)
PII: synthetic only; encrypt sensitive columns at rest if trivial
     (e.g. Fernet for email) — document approach in constitution

Naming: snake_case tables and columns
Timestamps: ISO-8601 text UTC unless noted
JSON columns: TEXT storing JSON arrays/objects

================================================================================

18. SEED DATA SPEC
--------------------------------------------------------------------------------
Candidates (3 minimum):
  1. Level I — engineering bg, exam in ~8 months, 10 h/week, KYC verified
  2. Level II — finance bg, 6 months out, mock scores seeded mid
  3. Level III pathway interest Private Wealth — near exam

Fees:
  Seed 2025 and 2026 tables matching knowledge_base fees_registration.md

Exam windows:
  Matrix months × levels; sample centers (city names synthetic)

Questions:
  ≥5 MCQs per major L1 topic (synthetic, clearly fake)

Study plan templates:
  Default week order Ethics → Quant → Eco → FSA → ... for L1

Notification templates:
  enrollment_confirmed, exam_reminder_7d, result_ready, kyc_flagged

Proctoring rules (config table optional or JSON file):
  face_missing_seconds > 5 → flag
  second_voice_detected → flag
  (synthetic thresholds only)

Admin user:
  profile_type=admin, name=Admin User
