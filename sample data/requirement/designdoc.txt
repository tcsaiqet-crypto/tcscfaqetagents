1. PROJECT OVERVIEW AND PURPOSE
--------------------------------------------------------------------------------
Build a single-repo Streamlit POC covering the full CFA candidate lifecycle:
registration → KYC → discovery → enrollment/payment → personalized learning →
AI tutor → mock exams → exam delivery/proctoring → results → digital certificate
→ notifications → support chatbot.

Governance: Speckit methodology inside Antigravity
  /speckit-constitution → /speckit-specify → /speckit-clarify →
  /speckit-plan → /speckit-tasks → /speckit-implement

Core product principle (constitution law):
  AI NARRATES, NEVER DECIDES.
  Eligibility, payment, scoring, KYC pass/fail, certificate issuance =
  pure deterministic Python + SQLite. Agents only explain/advise.

Sibling pattern reference: cfa-onboarding-poc
  (reuse spirit of rules-first + synthetic-only + offline-capable)

                                                          under CrewAI

                                                          Admin: provider dropdown +

Embeddings            OpenAI text-embedding-3-small       FROZEN after first build
                      (RECOMMENDED default)               Changing = rebuild ALL FAISS
                                                          Confirm before Phase 0 if
                                                          Gemini embeddings preferred
Vector store          FAISS (split indexes)               Local, offline, user choice.
                                                          Metadata filtering via SPLIT
                                                          indexes (not one giant index)
Business DB           SQLite  data/cfa_journey.db         Lightweight, offline, POC
Auth (POC)            Streamlit session_state             Simple; production out of scope
Chat memory           ConversationBufferWindowMemory k=8  + SQLite chat_sessions +
                                                          logs/chatdata/ JSON files
Secrets               .env via python-dotenv              Keys in /keys folder;
                                                          never commit; never print
Deploy                Local / Docker                      Demo and testing

Why FastAPI deferred:
  Streamlit + CrewAI same process. No external consumers yet.
  Extra uvicorn process adds debug cost with zero POC benefit.

Why CrewAI over LangGraph day-1:
  Product story = named specialists (tutor/planner/support).
  Hard rules stay in Python services, not in the LLM.

Why FAISS over Chroma/Pinecone/Qdrant/Weaviate:
  User choice + offline/local/offline.
  Weak metadata filter mitigated by domain-split indexes.

Embedding freeze rule:
  Chat model may switch freely at runtime.
  Embedding model must NOT switch after indexes are built.
  Rebuild indexes only via Admin → Vector Store Manager.

5. FAISS INDEX DESIGN
--------------------------------------------------------------------------------
faiss_indexes/
  curriculum_l1/      ← Level I topics, readings, LOS
  curriculum_l2/      ← Level II weights + available structure (partial)
  curriculum_l3/      ← Level III core + pathways (partial)
  policies_fees/      ← fees, windows, eligibility, reschedule, deferral
  faq_support/        ← FAQ + exam day + results/certification
  glossary/           ← CFA candidate terms
  question_bank/      ← synthetic MCQs (optional search)

Agent permission matrix:
  Router     → no index (page context + intent only)
  Tutor      → curriculum_l1 / l2 / l3 only
  Planner    → curriculum_* + question_bank + SQLite profile/progress
  Support    → faq_support + policies_fees (+ glossary fallback)

Grounding rules (non-negotiable):
  1. Answer ONLY from retrieved context
  2. If context empty → exact phrase:
       "I don't have that information. Please refer to the official
        CFA Institute website (cfainstitute.org)."
  3. Always cite source document/section when context used
  4. Fees / eligibility / pass-fail NEVER invented by LLM —
     those live in SQLite + Python rules; agents may only explain them

System prompt template (every agent):
  """
  You are {role} for CFA Digital Journey.
  Answer ONLY from the provided context blocks.
  If the answer is not in the context, say you don't have that
  information and refer the user to cfainstitute.org.
  Always cite the source document/section used.
  Never decide eligibility, payment status, exam scores, KYC
  outcomes, or certificate issuance. Those are system decisions.
  Active profile and page context are injected below — use them
  to personalize explanations, not to invent facts.
  """

Source files → indexes (see knowledgebase.txt for full map):
  knowledge_base/raw/curriculum_structure.md  → curriculum_l*
