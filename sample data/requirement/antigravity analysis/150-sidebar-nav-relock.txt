1. ROOT CAUSES IDENTIFIED & STRUCTURAL FIXES APPLIED
--------------------------------------------------------------------------------
BUG 1: Toggle Button Rendered as Blank White Square
- Root Cause: Usage of complex emoji or system-dependent icons that failed font rendering
  against default Streamlit button styles.
- Fix: Replaced with standard, universally-supported text glyphs ("«" when expanded, "»"
  when collapsed). Styled specifically with `.cfa-toggle-btn` rules for crisp dark-background
  contrast (#94A3B8 resting, #FFFFFF on hover).

BUG 2: Inactive Nav Items Rendered as Blank White Boxes with Invisible Text
- Root Cause: Over-broad CSS selector `section[data-testid="stSidebar"] * { color: #FFFFFF !important; }`
  forced white text on Streamlit's native button elements. Since Streamlit defaults to white
  button backgrounds when theme base is light, white text on white background created blank white
  boxes with invisible text.
- Fix: 
  1. Updated `.streamlit/config.toml` to `base = "dark"` with `backgroundColor = "#0B192C"`
     and `primaryColor = "#00D2FF"`.
  2. Removed the blanket `* { color: #FFFFFF !important; }` rule completely.
  3. Added scoped CSS targeting sidebar buttons specifically:
     `div[data-testid="stSidebar"] div.stButton > button { background: transparent !important; border: none !important; box-shadow: none !important; color: #C7D3E3 !important; }`
     This completely removes white background boxes and ensures readable text sitting directly
     on the navy background (#0B192C).

BUG 3: NameError: name 'width' is not defined (f-string CSS escaping)
- Root Cause: Single curly braces `{` and `}` inside `st.markdown(f""" <style>...</style> """)`
  were evaluated by Python as string interpolation expressions.
- Fix: Escaped all CSS block curly braces as double braces `{{` and `}}` throughout `app.py`.
