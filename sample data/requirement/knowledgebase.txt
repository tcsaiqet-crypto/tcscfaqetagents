1. PURPOSE AND RAG ARCHITECTURE OVERVIEW
--------------------------------------------------------------------------------
Goal: Ground every CFA-specific chatbot answer in retrieved documents so the
Tutor and Support agents cannot invent fees, rules, or curriculum facts.

Pipeline:
  raw markdown (NotebookLM / curated)
    → clean/split (processed/)
    → embed with FROZEN embedding model
    → FAISS index per domain
    → agent-scoped retriever tool
    → LLM answers ONLY from returned chunks
    → cite source; else I-don't-know

================================================================================

2. WHY SPLIT INDEXES (NOT ONE INDEX)
--------------------------------------------------------------------------------
FAISS metadata filtering is weak. One giant index risks:
  Candidate: "What is the Level I fee?"
  Retriever returns GIPS "investment management fee" chunk
  → catastrophic wrong answer

Split indexes + agent allow-lists enforce separation:
  Tutor never sees fee tables
  Support never teaches full LOS lists as if answering a study question
    without curriculum index (Support uses faq + policies only)

10. INGESTION RULES
--------------------------------------------------------------------------------
Splitter: LangChain RecursiveCharacterTextSplitter
  separators: ["\n## ", "\n### ", "\n\n", "\n", ". ", " "]
Embedding: OpenAI text-embedding-3-small  (DEFAULT — confirm D12)
  OR Gemini embedding if user picks B — then freeze that choice
Build: scripts/build_indexes.py
  reads knowledge_base/processed/*.md
  writes vector_store/faiss_indexes/{name}/
  writes build_meta.json (model name, timestamp, chunk counts)
Rebuild: Admin → Vector Store Manager → Rebuild
  OR upload new doc → append/rebuild that domain index only when possible

Never mix GIPS-firm-compliance v1 dumps into policies_fees or faq_support.

================================================================================

11. GROUNDING ENFORCEMENT
--------------------------------------------------------------------------------
Retriever returns top_k (default 4) chunks from ALLOWED indexes only.
Prompt packing order:
  1) System rules
  2) Profile + page context
  3) Retrieved chunks with source labels
  4) Last 8 messages
  5) User question

Empty retrieval template:
  "I don't have that information. Please refer to the official CFA Institute
   website (cfainstitute.org)."

Citation format in UI:
  Source: {filename} — {section_or_heading}

"I don't know" UI:
  Companion: plain text, no sources expander
  Main panel: collapsed [Not Available] with expand message
